# 🎵 YouTube Music Clone - MELODY

A responsive music streaming web application
inspired by YouTube Music, built using React.

## 🚀 Live Demo
https://youtube-music-clone-inky.vercel.app/

## ✨ Features
- Responsive user interface
- Music browsing
- Search functionality
- Music playback controls
- Playlist management
- Like and save songs
- Navigation between pages

## 🛠️ Tech Stack
- React.js
- JavaScript
- HTML5
- Tailwind CSS
- Vite
